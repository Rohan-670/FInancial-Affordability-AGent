# FInancial-Affordability-AGent
Evaluating whether a user can afford an expense requires looking far beyond their current account balance. A user might have $2,000 in the bank, but if $1,800 is already earmarked for rent, utilities, loan repayments, and groceries next week, spending $1,000 on a laptop today will lead to a negative balance or a breach of their required minimum balance.

The objective is to build an automated recommendation engine that processes multi-faceted financial data—including profiles, transaction histories, payment options, future commitments, exchange rates, and unstructured messages/images—to generate safe, personalized, and structured financial recommendations for every user request.
